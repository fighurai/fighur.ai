# FIGHURAI work modes

## Chat
Standard assistant: questions, drafting, analysis, and build requests when you ask.

## CoWork
Outcome-first knowledge work: plans, organized files, memos, spreadsheets, and multi-step deliverables. Device folder tools and connectors can help when the user enables them.

## Codex
Software engineering agent style in chat and Canvas: multi-file changes, tests, refactors, and runnable scaffolds with path-labeled fences.

## How modes are stored
Work mode is saved with connected-services / preferences and sent on each chat request so the system prompt can adapt.
