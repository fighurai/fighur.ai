# FIGHURAI Instagram carousel (11 slides)

Editorial cream / black carousel adapted from a visual-identity process format, rewritten for FIGHURAI’s AI consulting practice.

## Files

- `carousel.html` — source for all 11 slides
- `fonts/` — local Space Grotesk + DM Sans
- `exports/fighurai-carousel-01.png` … `11.png` — 1080×1080 Instagram-ready PNGs
- `export-slides.mjs` — re-exports PNGs via headless Chrome

## Regenerate

```bash
node assets/instagram-carousel/export-slides.mjs
```
